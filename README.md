# Python Quiz Game

A beginner-friendly command-line quiz game built with Python.

## Project Overview

This project is a simple interactive quiz game that asks users multiple-choice questions and calculates their final score.

The project was created to practice core Python programming concepts and user interaction.

## Features

- Multiple-choice questions
- Interactive user input
- Automatic answer checking
- Score calculation
- Final score display

## Python Concepts Used

- Functions
- Lists
- Dictionaries
- `for` loops
- Conditional statements
- `input()`
- String methods
- `enumerate()`
